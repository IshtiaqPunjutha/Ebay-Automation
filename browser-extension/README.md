# eBay to AliExpress Image Search

Load this folder once in Chrome to let the dashboard button upload an eBay
product image into AliExpress visual search.

1. In Chrome, open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select this `browser-extension` folder, the one containing `manifest.json`.
5. Return to the dashboard and click the search icon under an order image.

The extension only runs on AliExpress pages and only fetches product images
from `i.ebayimg.com`. AliExpress may still ask you to sign in or complete a
verification step before showing results.
